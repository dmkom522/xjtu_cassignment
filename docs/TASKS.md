# 9个人怎么分工

我们做一个简单的“期末周生存”文字游戏：5天，每天早、午、晚各选一次行动，最后看能不能过关。

**每个人只补自己负责的几个函数。** 文件、菜单输入、编译脚本和基础测试都已经准备好了。写完运行看看效果，再交一个PR；最后留10～15分钟一起把程序接起来。

这次减掉了两项：商店只卖咖啡、零食；随机事件只做排队、室友投喂。每个人不用另外写测试程序，也不用写长篇测试报告。

## 1号：把游戏串起来

打开 `src/game.cpp`，修改 `runGame()`。里面已经有选菜单、调用行动的代码，在这个基础上补：

- 记录现在是第几天、哪个时段。一共5天，每天3次行动。
- 行动成功后进入下一时段；取消或没买成就停在原时段。
- 每次行动后调用2号整理数值，调用7号检查有没有崩溃。
- 晚上调用6号的事件。还活着就进行夜间恢复；第5天晚上直接显示结局。

**做到：**能从第一天走到第五天，中途崩溃会结束。程序入口 `main.cpp` 已经有了，直接用。

## 2号：整理数值

打开 `src/state.cpp`，补两个函数：

- `normalize()`：三门课、精力、压力限制在0～100，金钱最低为0。
- `recoverAtNight()`：精力加15，压力减5，然后调用 `normalize()`。

**做到：**晚上能恢复，数字不会超过范围。大家要加公共声明时，你帮忙改 `include/game.h`，现有声明直接用。

## 3号：复习和休息

打开 `src/actions_basic.cpp`，补两个函数：

- `study()`：选中的课程加15，精力减15，压力加10。
- `rest()`：精力加30，压力减15。

做完返回 `true`。课程编号0是高数、1是英语、2是C++。

**做到：**选一次高数复习，高数从20变35；选休息后精力增加。

## 4号：娱乐和兼职

打开 `src/actions_extra.cpp`，补两个函数：

- `entertain()`：精力减5，压力减25。
- `work()`：金钱加20，精力减10，压力加5。

做完返回 `true`。**做到：**娱乐能减压力，兼职能加钱。

## 5号：商店

打开 `src/shop.cpp`，补 `buyItem()`。商品编号1是咖啡，2是零食：

- 咖啡15元：精力加25，压力加5。
- 零食10元：精力加5，压力减20。

钱够就扣钱、加效果，返回 `true`；钱不够返回 `false`。**做到：**两种商品都能买，一次只买一件。

## 6号：随机事件

打开 `src/events.cpp`，补三个小函数：

- `rollEvent()`：随机取0～3。取到0、1都返回0；取到2返回1；取到3返回2。
- `applyEvent()`：收到0就不做事；收到1就压力加4；收到2就精力加10。
- `eventText()`：分别返回“今天很平静”“打印资料排队”“室友投喂”。

**做到：**晚上有时没事，有时多一点压力，有时恢复一点精力。随机数工具已经放在函数参数里，直接用，不用统计概率。

## 7号：结局

打开 `src/endings.cpp`，补两个函数：

- `evaluateEnding()`：精力为0或压力达到100，返回 `Burnout`。还没结束时返回 `None`；走完5天后，三课都至少80返回 `Excellent`，否则都至少60返回 `Pass`，其余返回 `Retake`。
- `printEnding()`：给四种结局各打印一句话，再显示最终成绩。

**做到：**崩溃、学霸、过关、挂科四种结果能分清楚。

## 8号：把文字显示清楚

打开 `src/ui.cpp`。输入和菜单已经能用，主要补 `showChanges()`：把这次行动前后的数字相减，显示哪些数值变了。`showStatus()`的格式觉得不顺眼也可以调整。

**做到：**玩家能看清当前状态，以及刚才这次行动有什么效果。用普通文字即可。

## 9号：合并和试玩

大家提交PR后，你负责合并。现有编译脚本、自动测试直接用。

- 双击 `run.bat`，完整玩一局，看看每天能不能正常推进、最后有没有结局。
- 再连续复习，看看精力用完会不会结束。
- 在README里留几句启动方法；发现问题交给对应成员改。

**做到：**大家的代码接起来能玩。你不需要另外写自动测试、重新搭编译环境或整理一大堆报告。

## 大家统一记住这三件事

1. 函数名字和参数已经写在 `include/game.h`，照着填函数体。
2. 3～6号只负责改数值，读菜单和推进时间交给1号、8号。
3. 写完自己运行看一下，PR里写“我做了什么、运行看到了什么”即可。
