# 这版游戏怎么玩

5天，每天早、午、晚各行动一次，共15次。复习高数、英语、C++，最后把复习进度当成成绩。

## 开始时

三门课各20，精力70，压力20，金钱30。课程、精力、压力都在0～100之间。

## 每次可以做什么

| 行动 | 数值变化 |
|---|---|
| 复习一门课 | 该课+15，精力-15，压力+10 |
| 休息 | 精力+30，压力-15 |
| 娱乐 | 精力-5，压力-25 |
| 兼职 | 金钱+20，精力-10，压力+5 |
| 买咖啡，15元 | 精力+25，压力+5 |
| 买零食，10元 | 精力+5，压力-20 |

成功做一件事就用掉一个时段；取消或钱不够不耗时。属性到上限后按100计算。

## 一天怎么结束

每次行动后，先整理数值、检查是否崩溃。到了晚上，再随机发生一件事：一半概率没事，四分之一概率压力+4，四分之一概率精力+10。

事件后再检查一次崩溃。第1～4天还活着，就精力+15、压力-5，进入第二天；第5天晚上直接结算。

## 四种结局

1. 精力为0或压力达到100：崩溃，提前结束。
2. 坚持到最后，三门课都至少80：学霸。
3. 否则，三门课都至少60：过关。
4. 其他情况：挂科。

先判断崩溃，再判断成绩。首版保留这些内容，商店只有两种商品，事件只有两种。
